# Flutter Lab Sheet 3

Flutter User Input and Basic Interaction — 25 programs.

## Run on Chrome

Clone the repository:

```bash
cd ~/Desktop
git clone https://github.com/NetraChauhan/flutter_lab_sheet_3.git
cd flutter_lab_sheet_3
flutter pub get
```

Run any program separately:

```bash
flutter run -d chrome -t lib/program_01.dart
```

For the next program, stop the current run with `q`, then change the file number:

```bash
flutter run -d chrome -t lib/program_02.dart
```

Continue the same way up to `program_25.dart`.
